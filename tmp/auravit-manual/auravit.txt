1.0 GENERAL INFORMATION

This User's Manual provides instructions for accessing and operating AuraVit, a digital
reproductive-health platform designed to provide reproductive-health education,
informational assistance, Human Support, appointment services, health tracking, clinical
records, notifications, and privacy-management functions for Patients.

The manual describes the major functions available to Patients and provides step-by-step
procedures for using the AuraVit web and mobile applications.




1.1 SYSTEM OVERVIEW

AuraVit is a digital health platform integrated with reproductive-health education. The
system is designed to provide accessible reproductive-health information and digital
services through web and mobile applications.

Patients can access educational materials through the Learn module, obtain informational
assistance through AskAuri, communicate with Peer Educators through Human Support,
schedule appointments with healthcare providers, review available clinical records, receive
notifications, and manage their account and privacy settings.

For mobile users, AuraVit also provides applicable health-tracking features such as the
Symptoms & Cycle Tracker and Habit Tracker.

AuraVit is intended to provide reproductive-health information, support, tracking,
appointment,    and    authorized      record-management     services.   AskAuri    provides
informational guidance and does not replace professional medical diagnosis or
treatment.




1.2 ORGANIZATIONAL STRUCTURE OF THE USER'S MANUAL

This User's Manual is divided into the following major sections:

General Information provides an overview of the AuraVit System, its purpose, intended user,
and the organization of this manual.

System Summary describes the general system configuration, supported platforms,
requirements, and Patient access level.

Getting Started provides instructions for accessing the AuraVit web application and
installing or accessing the mobile application.

Using the System provides detailed instructions for operating the functions available to
Patients.



2.0 SYSTEM SUMMARY

This section provides an overview of the AuraVit System, including its configuration, software
and hardware requirements, supported platforms, and Patient access level.
2.1 SYSTEM CONFIGURATION

AuraVit consists of a web application and a mobile application that provide Patients with
access to reproductive-health information and digital health services.

The web application provides Patients with access to applicable AuraVit functions through a
supported web browser.

The mobile application is primarily designed to provide Patients with convenient access to
reproductive-health education, AskAuri, Human Support, appointments, clinical
information, health tracking, notifications, and account-management functions.

AuraVit uses account-based access to ensure that Patients can access functions and
information associated with their authorized account.



2.2 SOFTWARE AND HARDWARE REQUIREMENTS

To access and use AuraVit, the Patient should have the following:

For the Web Application

   1. A desktop computer, laptop, tablet, or supported mobile device.

   2. A stable internet connection.

   3. A supported modern web browser such as:

          o   Google Chrome

          o   Microsoft Edge

          o   Mozilla Firefox

          o   Safari, where supported

   4. A valid AuraVit account.

For the Mobile Application
   1. A compatible mobile device.

   2. A stable internet connection through Wi-Fi or mobile data.

   3. Sufficient device storage for installation.

   4. The provided AuraVit mobile application package or installation link.

   5. A valid AuraVit Patient account.




2.3 USER'S ACCESS LEVEL

Patient

The Patient is the primary end-user of the AuraVit System. Patients are authorized to access
the system's available reproductive-health education, informational assistance, support
services, appointment services, health tracking, authorized health records, notifications,
and account and privacy management functions.

Access to information and system functions is limited to the permissions associated with
the Patient's account.

    5.0 Mobile User
The Mobile User refers to a registered AuraVit user who accesses the platform through the
mobile application. The AuraVit Mobile Application provides users with access to
reproductive health education, AI-assisted and human support, appointment scheduling,
digital health records, health tracking tools, notifications, and personal account and privacy
management.

The application provides health-monitoring features for users, including symptom tracking,
mood logging, and habit tracking. Female users are additionally provided with a menstrual
cycle tracker, which allows them to record menstrual period information and monitor their
cycle history. Based on the information recorded by the user, the system may provide
estimated menstrual cycle phases, fertile-window and ovulation information, and upcoming
period predictions.

AuraVit's health-tracking information is intended to support personal reproductive health
awareness and monitoring and does not provide medical diagnosis or treatment. Cycle
patterns and predictions are based on user-provided information and algorithmic estimates.
